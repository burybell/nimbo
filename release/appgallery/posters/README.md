# AppGallery poster sources

The five upload-ready images in `../screenshots/` are generated from maximized Nimbo screenshots without stretching.

- Raw captures: 3120 × 2080 px; the 3120 × 1755 application area is cropped at its original ratio.
- Poster canvas: 1920 × 1080 px.
- Embedded interface: 1504 × 846 px (exactly 16:9).
- Typeface: HarmonyOS Sans SC from the DevEco Studio preview runtime.
- Generator: `../../../scripts/generate-appgallery-posters.sh`.

The background plate was generated with the built-in image tool using this prompt:

> Elegant minimal 16:9 AppGallery poster background for Nimbo, with restrained periwinkle, pale lavender, cool white, subtle mint accents, soft flowing translucent ribbons, generous headline space, and no text, logo, device, window, or watermark.
