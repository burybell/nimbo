# Nimbo 隐私政策

更新日期：2026 年 9 月 11 日  
生效日期：2026 年 9 月 11 日

Nimbo（以下简称“本应用”）是一款本地优先的 API 调试工具，由【运营者名称】（以下简称“我们”）向您提供。我们重视您的隐私和个人信息安全。本政策用于说明本应用如何处理与保护您的信息，以及您享有的相关权利。

请您在使用本应用前仔细阅读本政策。若您不同意本政策的内容，请停止使用本应用。

## 一、我们如何处理信息

### 1. 本地保存的内容

为实现 API 请求编辑、调试和工作区恢复等功能，本应用会在您的设备本地保存您主动创建、输入或导入的以下内容：

- 请求地址、请求方法、查询参数、请求标头、认证配置和请求正文；
- 集合、文件夹、请求名称及其组织结构；
- 环境名称、环境变量及变量值；
- 请求历史、响应状态及必要的调试信息；
- 语言、主题、字体、超时时间、历史记录保留期限等应用设置；
- 您主动导入的 cURL、Postman Collection 或 Postman Environment 内容。

上述内容默认保存在您的设备本地，我们不会将其上传至我们的服务器，也不会基于这些内容进行用户画像、广告推荐或数据分析。部分请求内容可能包含访问令牌、Cookie、密码、密钥或其他敏感信息，请您妥善保管设备，并根据需要使用本应用提供的敏感信息遮罩功能。

### 2. 您主动发送的网络请求

当您点击“发送”时，本应用会按照您填写的请求地址、参数、标头、认证信息和请求正文，向您指定的服务器发送网络请求，并接收该服务器返回的响应。这是本应用实现 API 调试功能所必需的处理。

请求数据的接收方是您自行指定的目标服务器，而不是我们。目标服务器如何处理相关数据，由该服务器的运营者及其隐私政策决定。请您仅向您有权访问和测试的服务器发送请求，并避免在没有合法依据的情况下发送他人的个人信息、商业秘密或其他受保护数据。

若您关闭 SSL 证书校验，网络请求可能面临中间人攻击、数据泄露等风险。请仅在可信测试环境中使用该选项。

### 3. 文件的读取与保存

在您主动选择文件时，本应用可能读取您选定的文件，用于：

- 导入 Postman Collection 或 Environment；
- 将文件作为二进制请求体或多部分表单的一部分发送至您指定的服务器；
- 在本地预览接口返回的图片或视频。

本应用不会在未经您选择的情况下遍历或读取设备中的其他文件。接口响应的复制、下载和导出仅在您主动操作时进行，文件会保存到您选择的位置。用于图片或视频预览的临时文件可能存放在应用缓存目录，并可由操作系统按缓存管理机制清理。

### 4. 剪贴板

当您主动点击复制请求内容、复制响应内容等功能时，本应用会将相应文本写入系统剪贴板。本应用不会在后台持续读取或收集您的剪贴板内容。

### 5. 权限使用

本应用目前仅申请互联网访问权限，用于向您指定的服务器发送请求并接收响应。选择文件和保存文件通过系统文件选择器完成，仅访问您主动选择或授权的文件。

### 6. 我们不收集的信息

当前版本不提供用户注册或登录功能，不接入广告、统计分析、用户画像或第三方追踪 SDK。我们不会主动收集您的姓名、手机号码、电子邮箱、精确位置、通讯录、设备标识、相册、麦克风、摄像头、支付信息或生物识别信息。

## 二、信息的共享、转让和公开披露

我们不会出售、出租、交换或向第三方共享您的个人信息，也不会将本应用本地保存的数据转让或公开披露。

需要特别说明的是：您主动向指定服务器发送 API 请求时，请求内容会传输给该服务器。这属于您为实现调试目的而主动指定的传输，并非我们向第三方共享您的数据。

如法律法规、司法机关或行政主管部门依法要求我们提供相关信息，我们将在法律允许的范围内配合。但由于当前版本的数据默认仅保存在您的设备本地，我们通常无法访问这些数据。

## 三、信息的保存期限和安全保护

本应用在设备本地保存数据，保存期限由您的使用和设置决定。请求历史是否保存及其保留期限可在设置中调整。您可以在应用内删除相应的请求、集合、环境变量或历史记录，也可以通过操作系统清除本应用数据或卸载本应用来删除本地数据。

我们采取与本应用功能相适应的安全措施，尽力防止数据被未经授权访问、篡改、披露或丢失。但互联网传输和本地设备环境无法保证绝对安全，请勿在不可信网络或不可信设备上处理重要密钥和生产环境凭据。

## 四、您的权利

对于保存在您设备本地的数据，您可以直接在本应用内进行查看、修改或删除；也可以通过清除应用数据或卸载本应用删除全部本地数据。

如果您对本政策或个人信息处理有疑问、意见或投诉，或者希望行使法律法规规定的查阅、复制、更正、删除、撤回同意等权利，可通过本政策第八部分所列方式联系我们。我们将在核实您的请求后，于法律法规规定的期限内答复。

## 五、未成年人保护

本应用是面向开发者的专业工具，不以未成年人为主要服务对象。未成年人应在父母或其他监护人的指导和同意下使用本应用，不应通过本应用发送本人或他人的敏感个人信息。如监护人发现未成年人不当提供了个人信息，可联系我们处理。

## 六、第三方服务与链接

本应用允许您访问自行输入的网络地址。此类网站、接口或服务由相应第三方独立运营，其数据处理行为不受本政策约束。建议您在发送请求前查看并遵守目标服务的隐私政策、用户协议和接口使用规则。

当前版本未集成用于广告、统计、登录或支付的第三方 SDK。如后续版本新增会处理个人信息的第三方 SDK 或服务，我们将依法更新本政策并进行必要告知。

## 七、本政策的更新

我们可能根据功能变化或法律法规要求更新本政策。若更新对您的权益产生重大影响，我们将通过应用内提示、应用市场页面或其他适当方式告知您。未经您明确同意，我们不会削减您依据本政策享有的权利。
